# 第4難易度「ぷろ」＋残機（誤答ペナルティ）

## 背景 / 決定済み方針
- 残機は no-fail 原則と衝突するため、**新難易度「ぷろ」限定のオプトイン**として追加。
- やさしい/ふつう/むずかしいは引き続き完全 no-fail。

## 難易度マトリクス（ユーザー指定）
| モード | スクロール(pan/zoom) | 点滅 | 残機 |
|--------|:---:|:---:|:---:|
| easy   | ✗ | ✗ | ✗ |
| normal | ✗ | ✓ | ✗ |  ← 現行(scroll有/点滅無)から組み替え
| hard   | ✓ | ✓ | ✗ |
| pro    | ✓ | ✓ | ✓ |  ← 新規

→ GameMode に能力フラグを持たせて整理（DRY）:
  `bool get scrolls`  = hard || pro
  `bool get blinks`   = normal || hard || pro
  `bool get hasLives` = pro

現行の `_isLargeArea => mode != easy` と「点滅= hard のみ」を上記に置換。

## 残機の仕様（推奨・要確認）
- 残機数: **3（♥♥♥）**。ステージ入場ごとに満タン（per-scene）。
- 失う条件: **ダミー(おとり)をタップ＝誤答で −1**（要確認: 空振りも対象にするか）。
  - 消失中の宝・残り1つの保護は維持（罰なし）。
  - ぷろではおとりの「つつくイースターエッグ(#6)」は無効化（誤答=失点に置換）。
    easy/normal/hard では従来どおりイースターエッグのまま。
- 0 になったら: **やさしく同じステージを再挑戦**（「もういちど さがそう！」→
  残機満タン・配置リシャッフルでリスタート）。×・減点・不快音・順位なし。
- ヘッダー(オーバーレイ)に ♥♥♥ を表示。失うと 1 つ減る簡素な演出。

## 解放条件（要確認）
- 現状 hard はトグルで常時選択可（ゲートなし）。
- ぷろを「むずかしいで全ワールドクリアで解放」とするか、最初から選べるか。
